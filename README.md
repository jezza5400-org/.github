# jezza5400-org

Welcome to the jezza5400-org organization repository.

This repository contains default community health files and organization-wide settings for all repositories in this organization.

## What is this?

This is a special `.github` repository that GitHub uses to provide default files (like CONTRIBUTING.md, CODE_OF_CONDUCT.md, etc.) for all repositories in the organization that don't have their own versions.
